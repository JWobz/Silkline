Recording what the API still needs

For Silkline (docs/protocol.md). One Wireshark recording for the whole session; this page notes the time of every step so the two can be lined up afterwards. Your notes are kept in this browser if you reload, but download the log at the end.

Before you start

  1. Amp plugged into the PC (not the Pi), Spider V Remote open and connected.
  2. Wireshark open. Start recording on the amp's USBPcap interface (the one you used last time).
  3. Leave about 5 seconds between actions, and press Done on a step as soon as you've finished it. The times matter more than tidy notes.
  4. Nothing here is saved on the amp except step 7, which says so first.

Finish

  1. Stop the Wireshark recording and File > Save As captures\windows\session.pcapng (in the silkline folder).
  2. Press Download log (top right) and move the file into the same folder.
  3. Unplug the amp from the PC and plug it back into the Pi.
